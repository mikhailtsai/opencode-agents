# OpenCode Agents Experiment

I'm experimenting with OpenCode and local AI agents on a machine with 12 GB VRAM and 32 GB RAM.

With limited hardware, I can't solve every problem simply by using larger models or increasing model parameters. Instead, I'm exploring how orchestration and specialized subagents can make smaller local models more effective.

The goal is to experiment with agent roles, task delegation, and orchestration patterns to get better results from the hardware I already have.

In the future, I plan to use the same architecture with cloud AI models as well, with the goal of reducing token costs while improving overall productivity.
